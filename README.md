# 🧭 سامانه هوشمند مهاجرت از ایران (IraMigrate AI - 2026)

سامانه جامع تحلیل و ارزیابی شرایط مهاجرت بر اساس آخرین قوانین ۲۰۲۶، رادار زنده فرصت‌های تحصیلی و کاری، شبیه‌ساز مصاحبه سفارت، و نقشه راه ۷ فازه.

---

## 💻 راهنمای اجرای پروژه در مک و لینوکس / ویندوز

### نصب وابستگی‌ها و اجرا:
```bash
npm install
npm run dev
```
سپس آدرس `http://localhost:3000` را در مرورگر باز کنید.

---

## 🔄 نحوه بازیابی خودکار تمام گفتگوها در نسخه مک (Antigravity on macOS):

اگر آنتی‌گرویتی را روی مک نصب کرده‌اید و گفتگوهای قبلی شما در سایدبار نیستند، تمام تاریخچه چت‌ها و پرونده‌ها در پوشه `.antigravity-backup/` ذخیره شده است.

### روش ۱ (ساده‌ترین روش - فقط با گفتن به من در مک):
کافیست در آنتی‌گرویتی مک این ریپازیتوری را باز کنید و در چت بنویسید:
> **«گفتگوها رو برگردون»**

دستیار هوش مصنوعی اسکریپت بازیابی را خودکار اجرا کرده و تمام گفتگوها به سایدبار برمی‌گردند.

### روش ۲ (دستور مستقیم در ترمینال مک):
```bash
npm run restore:conversations
# یا دستور مستقیم:
bash .antigravity-backup/restore_on_mac.sh
```
سپس برنامه Antigravity را یکبار باز و بسته (Restart) کنید تا تمامی ۸ گفتگو در منوی چت لود شوند.
